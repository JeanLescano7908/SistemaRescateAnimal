Sistema de Control de Rescate y Adopción Animal

Asignatura: Desarrollo de Sistemas Informáticos
Universidad Técnica de Manabí
Periodo académico: septiembre-enero 2026

Descripción:
Proyecto destinado al análisis, diseño y
desarrollo de un sistema informático para gestionar rescates,
